## 활동내용

### 1교시 (45분) - 백엔드 개념 + 다 함께 프롬프트

1. **완성 제품의 백엔드 시연 + DB 개념 강의 (15분)**
   - 선생님이 사전에 완성해 둔 "AI 공부 매니저"의 데이터가 어떻게 저장되고 조회되는지, 실제 SQLite DB 파일을 열어 보여주며 백엔드의 역할을 설명하였습니다.
   - 프론트엔드(사용자 화면)와 백엔드(데이터 처리)의 차이를 식당의 홀·주방 비유로 압축하고, SQLite 테이블·컬럼·행 구조를 시각적으로 설명하였습니다.
   - 팀별로 자신의 앱에 필요한 데이터 목록(테이블·컬럼)을 1~2분 안에 빠르게 정리하였습니다. 예: 공부 타이머 → `study_records(id, 날짜, 과목, 공부시간, 메모)`.

2. **다 함께 프롬프트 - Flask + SQLite 연동 (15분)**
   - 선생님 화면에서 학생들과 함께 첫 번째 프롬프트를 만들었습니다: "Flask에서 SQLite DB를 연결하고, 공부 기록을 저장·조회하는 코드를 만들어 줘."
   - 생성된 코드를 다 같이 읽으며 `sqlite3.connect`, `cursor.execute`, `@app.route('/save', methods=['POST'])` 등 핵심 개념을 짚었습니다.
   - 두 번째 프롬프트로 "저장된 기록을 삭제하는 기능도 추가해줘"를 즉석에서 붙여 CRUD 흐름을 완성하는 과정을 시연하였습니다.

3. **팀별 백엔드 코드 생성 및 각자 실행 (15분)**
   - 각 팀이 자기 앱의 DB 설계를 바탕으로 Claude에게 백엔드 코드를 요청하여 생성하였습니다.
   - 각자 노트북에서 코드를 실행하고, 브라우저에서 데이터를 입력·저장해 본 뒤 DB Browser for SQLite로 저장 여부를 눈으로 확인하였습니다.

### 2교시 (45분) - 프론트-백엔드 연동 + 최종 발표

4. **프론트엔드-백엔드 연동 및 통합 테스트 (20분)**
   - 3회차에 만든 프론트엔드 화면의 입력 폼과 4회차 백엔드 API를 `fetch()`로 연결하는 코드를 Claude에게 요청하여 붙였습니다.
   - 사용자가 화면에 입력한 데이터가 서버로 전송·저장되고, 저장된 데이터가 다시 화면에 표시되는 전체 흐름을 팀별로 완성하였습니다.
   - 오류가 나면 오류 메시지 전체를 Claude에게 붙여넣어 원인을 파악·수정하는 디버깅 습관을 반복하였습니다.
   - 팀원들이 서로의 앱을 사용자 입장에서 사용해 보며 버그와 개선점을 즉석에서 수정하는 페어 테스트를 진행하였습니다.

5. **팀별 최종 발표 및 회고 (20분)**
   - 팀별 3분씩 시연 발표하였습니다. 발표 항목: 앱 이름, 해결한 문제, 핵심 기능 시연, 인상 깊었던 프롬프트, 다음에 개선하고 싶은 점.
   - 4회차 여정을 돌아보며 "가장 어려웠던 순간", "가장 뿌듯했던 순간", "AI와 함께 코딩하며 배운 것"을 짧게 나누는 회고 시간을 가졌습니다.

6. **수료 및 향후 학습 로드맵 안내 (5분)**
   - GitHub에 최종 커밋·푸시하고 README.md를 정리하여 자신의 포트폴리오로 남기는 방법을 안내하였습니다.
   - 다음 단계 도전 과제(모바일 앱, 배포, 데이터 시각화 등)를 소개하고 참고 자료를 공유하였습니다.

## 활동소감

90분이라는 짧은 시간 안에 백엔드 개념 이해·CRUD 구현·프론트/백 연동·최종 발표까지 소화해야 했기 때문에, 선생님 화면에서 다 함께 프롬프트를 만드는 시연과 팀별로 자기 프롬프트를 작성해 실행하는 실습을 짧게 교차하는 방식으로 진행하였습니다. "백엔드는 어렵다"는 처음의 두려움이 Claude와 함께 한 줄씩 만들어 가면서 "이해할 수 있는 코드"로 바뀌는 모습이 인상적이었습니다. 최종 발표에서 학생들이 자기 앱을 소개하는 모습에서 "지식 소비자에서 생산자로"라는 프로젝트 목표가 실현되는 것을 확인할 수 있었습니다.
