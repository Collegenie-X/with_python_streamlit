## 활동내용

### 1교시 (45분) - 수업 방식 안내 + 바이브 코딩 실전 사례

1. **수업 방식 오리엔테이션 (10분)**
   - 이번 프로젝트는 4명이 한 팀을 이루어 **하나의 주제로 완성된 웹앱을 만드는 것**이 목표임을 명확히 공유하였습니다.
   - 4회차 동안 회차별로 "OT·기획 → 환경 셋팅·설계 → 프론트엔드 → 백엔드"의 흐름으로 진행되며, 각 회차는 90분(45분+45분) 짧은 템포로 밀도 있게 진행됨을 안내하였습니다.
   - 이 수업의 핵심은 "코드를 직접 치는 능력"이 아니라 **"기획하고, AI에게 요청하고, 결과를 판단·수정하는 능력"**임을 강조하였습니다.

2. **바이브 코딩 실전 사례 소개 - "링고팡" (20분)**
   - 실제로 소스 코드를 **한 줄도 직접 수정하지 않고 바이브 코딩만으로 완성한 서비스 "링고팡"** 사례를 자세히 소개하였습니다.
   - 링고팡이 어떤 기획으로 시작되었고, 어떤 프롬프트를 어떤 순서로 던져 완성되었는지, 그리고 결과물이 실제 사용자들에게 서비스되기까지의 전체 과정을 화면과 함께 시연하였습니다.
   - "AI에게 잘 요청하는 사람은, 코드를 못 짜도 실제 상용 서비스를 만들 수 있다"는 것을 학생들이 눈으로 확인할 수 있도록 코드 저장소·프롬프트 기록·서비스 화면을 순서대로 보여주었습니다.
   - 이 실전 사례를 통해 "바이브 코딩은 장난감이 아니라 실제 상용화가 가능한 개발 방식"임을 각인시켰습니다.

3. **코딩 교육의 변화와 프로젝트/기획 중심 교육의 중요성 (15분)**
   - 기존 코딩 교육(문법 암기 → 예제 따라 치기)의 한계를 지적하고, AI 시대에는 **"기획·문제 정의·프로젝트 완성 경험"**이 훨씬 중요해졌음을 설명하였습니다.
   - 아무리 좋은 도구(Claude, Cursor 등)가 있어도 "무엇을 왜 만들 것인가"에 대한 기획이 없으면 결과물은 만들어지지 않음을 강조하였습니다.
   - 링고팡 사례에서도 결국 성공을 좌우한 것은 "어떤 문제를 해결할 것인가"에 대한 명확한 기획과, 그것을 프롬프트로 풀어내는 능력이었음을 짚었습니다.
   - 그래서 이번 4회차 수업 역시 "코드 문법"이 아니라 "팀으로 하나의 프로젝트를 완성하는 경험"에 초점을 맞춘다는 점을 다시 강조하였습니다.

### 2교시 (45분) - 팀 빌딩 + 다 함께 바이브 코딩 체험

4. **팀 빌딩 및 그라운드 룰 (15분)**
   - 4명씩 1개 팀을 구성하고, 팀 이름·역할(팀장·서기·발표자·시연자)을 정하며 팀별 그라운드 룰을 정리하였습니다.
   - 각자 자기소개(관심 분야, 평소 불편했던 점, 이번 수업에서 기대하는 것)를 짧게 나누며 이후 아이디어 논의의 기반을 마련하였습니다.

5. **다 함께 프롬프트 실습 - 선생님 화면 (25분)**
   - 선생님 화면을 크게 띄우고, 학생들이 함께 프롬프트를 만들어 보는 참여형 시연을 진행하였습니다.
   - **첫 번째 프롬프트**: "간단한 공부 타이머 웹앱을 만들어 줘"를 학생들과 함께 다듬어 Claude에게 입력하고, 실시간으로 코드가 생성되는 과정을 함께 보았습니다.
   - **두 번째 프롬프트**: 첫 결과물을 보고 "버튼 색을 바꿔줘", "알림 소리 추가해줘"처럼 학생들이 즉석에서 낸 아이디어를 추가 프롬프트로 반영하여 개선하는 과정을 시연하였습니다.
   - 학생들은 자신들이 낸 의견이 바로 코드와 화면에 반영되는 것을 보며 "AI에게 요청하는 감각"을 체감하였습니다.

6. **다음 회차 준비사항 안내 (5분)**
   - 2회차에는 10가지 앱 주제 중 팀별로 무엇을 만들지 선정하는 시간이 있음을 예고하고, Python·VS Code 설치와 Claude AI 가입을 안내하였습니다.

## 활동소감

1일차 1교시는 "왜 바이브 코딩인가"에 대한 신뢰를 심어주는 것이 핵심이었습니다. 특히 링고팡처럼 소스 코드를 한 줄도 직접 수정하지 않고 바이브 코딩만으로 완성된 실제 상용 서비스 사례를 보여주었을 때, 학생들이 "정말 그게 가능하냐"며 크게 몰입하였고, 이를 계기로 "코딩보다 기획이 중요하다"는 메시지가 자연스럽게 전달되었습니다. 2교시에는 팀 빌딩 후 선생님 화면에서 2개의 프롬프트를 함께 만들어 보는 방식으로 진행하여 90분 안에 몰입도를 유지하며 진도를 마칠 수 있었습니다.

## 특이사항 및 요청사항

- 링고팡 사례가 학생들의 몰입도를 크게 높였습니다. 이후 회차에도 실제 상용 서비스 사례를 짧게 삽입하는 방식을 이어가겠습니다.
- 다음 회차부터 학생 각자 노트북에서 직접 개발 환경을 셋팅할 예정이므로, Python·VS Code 설치 가이드 문서를 사무국을 통해 사전 배포 요청드립니다.
- Claude AI 계정 생성 시 학부모 동의가 필요한 학생들이 있어, 안내문 발송을 요청드립니다.
