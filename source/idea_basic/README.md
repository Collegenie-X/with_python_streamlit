# 2·3·4차시용 프론트엔드 예시 코드 (10가지 프로젝트 아이디어)

`다가치-수업/프론트엔드_개발의_한계와_아이디어_10선.md`의 10가지 아이디어를 각각
**하나의 완성된 메인 페이지**처럼 구현한 Streamlit 예시입니다. 단순 기능 조각이 아니라,
① `st.set_page_config`로 앱 기본 설정 → ② 사이드바에 서비스 소개/설정 →
③ 상단 타이틀·요약 지표(히어로 섹션) → ④ 핵심 기능(입력→처리→결과) 순서로
실제 서비스 첫 화면을 여는 구조를 갖추고 있습니다.

학생들이 2차시(입력 화면) → 3차시(핵심 기능) → 4차시(완성/시각화)로 나아갈 때,
"완성된 메인 페이지가 이런 모습이구나"를 먼저 보고 거꾸로 따라 만들 수 있도록 구성했습니다.

```bash
streamlit run idea_examples/<폴더명>/app.py
```

| 폴더 | 아이디어 | 메인 페이지 구성 | 핵심으로 배우는 프론트 기능 |
|---|---|---|---|
| 01_emotion_escape_room | 감정 방탈출 게임 | 랜딩(감정 선택) → 방 → 엔딩 3단계 화면 | `session_state` 화면 전환, `radio`, `container` 카드 |
| 02_school_survey | 우리 학교 설문 리서치 툴 | 사이드바 누적 응답 수 + 응답/결과 탭 | `tabs`, `form`, `groupby` + `bar_chart` |
| 03_taste_recommender | 취향 추천 테스트 (MBTI 스타일) | 시작 → 퀴즈 → 결과 3단계 화면 | `progress`, 단계별 분기, 점수 합산 |
| 04_meal_review | 급식 별점 & 리뷰판 | 상단 지표 카드 + 입력/목록 2단 레이아웃 | `form`, `container(border=True)` 카드 |
| 05_study_timer | 공부 타이머 & 집중 기록기 | 상단 대시보드 지표 + 시작/종료 상태 전환 | 버튼 상태 전환, `metric`, `bar_chart` |
| 06_ai_tutor_chatbot | AI 과목 튜터 챗봇 | 사이드바 과목 선택 + 채팅 메인 화면 | `selectbox`, `chat_input`, `chat_message` |
| 07_playlist_mood | 플레이리스트 무드 추천기 | 히어로 소개 + 추천 결과 + 히스토리 | `selectbox` 조합 분기, `balloons` |
| 08_allowance_ledger | 용돈 가계부 & 소비 분석 | 상단 예산 지표 카드 + 입력/분석 2단 레이아웃 | `form`, `groupby` + `bar_chart`, `metric delta` |
| 09_class_timetable | 우리 반 시간표 & 준비물 알리미 | 사이드바 "오늘로 이동" + 요일별 체크리스트 | 딕셔너리 데이터, `checkbox`, `columns` |
| 10_climate_dashboard | 환경·기후 데이터 대시보드 | 사이드바 필터 패널 + 지표 카드 + 다중 차트 | `sidebar` 필터, `line_chart`, `expander` |

## 차시별 활용 가이드

- **2차시 (기획 & 첫 화면)**: 각 앱의 입력 화면 부분만 먼저 따라 만들어 보고,
  `session_state` 초기화 구조를 이해합니다.
- **3차시 (핵심 기능 완성)**: 화면 전환/저장/집계 로직을 추가하며 완성도를 높입니다.
- **4차시 (완성 & 발표)**: 차트, 카드 레이아웃, 메시지(success/balloons 등)로
  마무리하고 팀 발표를 준비합니다.

각 파일은 독립적으로 실행 가능한 최소 예시이며, 팀 프로젝트에 맞게 자유롭게
수정·확장하면 됩니다.
