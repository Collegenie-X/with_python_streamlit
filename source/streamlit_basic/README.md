# Streamlit 예시 코드 모음

`Streamlit_사용법_기본함수.md`의 내용을 주제별 폴더로 나눈 예시 코드입니다.
각 폴더에서 아래처럼 실행할 수 있습니다.

```bash
streamlit run examples/<폴더명>/app.py
```

| 폴더 | 주제 |
|---|---|
| 01_text_output | 텍스트 출력 (title, header, write, markdown 등) |
| 02_data_display | 데이터프레임/테이블/JSON 출력 |
| 03_input_widgets | 입력 위젯 (text_input, slider, selectbox, file_uploader 등) |
| 04_charts | 차트 (line_chart, bar_chart, area_chart, matplotlib) |
| 05_layout | 레이아웃 (sidebar, columns, tabs, expander) |
| 06_session_state | 상태 유지 (session_state) |
| 07_caching | 캐싱 (@st.cache_data) |
| 08_status_messages | 상태 메시지 (success, error, spinner, balloons) |
| 09_data_science_dashboard | 데이터 사이언스 대시보드 종합 예제 |
